# 🛡️ Safe Reporting App

**אפליקציה לניהול דיווחי בטיחות של עובדים**, עם היררכיית משתמשים ברורה:  
**Admin → Manager → Employee**.

---

## 👥 היררכיית משתמשים והרשאות

| תפקיד        | הרשאות עיקריות |
|--------------|----------------|
| **Admin**    | - יכול לנהל את כל המנהלים והעובדים<br>- לראות את כל הדיווחים וההתראות<br>-  manager ליצור|
| **Manager**  | - יכול לנהל רק עובדים השייכים לו<br>- לראות דיווחים מהעובדים שלו<br>- לקבל התראות על דיווחים ״בטוח/לא בטוח״ |
| **Employee** | - יכול לדווח על מצב בטיחות<br>- יכול לסמן אם הוא **בטוח / לא בטוח**<br>- יכול להוסיף סיבה ומיקום |

---

## 📊 פונקציונליות עיקרית

### 1️⃣ דיווחים בזמן אמת
- עובדים יכולים לסמן **בטוח / לא בטוח**.
- ניתן להוסיף סיבה וטקסט חופשי לדיווחים "לא בטוחים".

### 2️⃣ ניהול התראות
- יצירת התראה אוטומטית על דיווחים "לא בטוחים".
- מנהלים יכולים **לסמן טיפול בוצע**.

### 3️⃣ דשבורד
- **Admin:** רואה את כל המשתמשים, דיווחים, התראות וסטטיסטיקות.
- **Manager:** רואה דיווחים והודעות רק מהעובדים השייכים לו.
- סטטיסטיקות בזמן אמת: מספר דיווחים בטוחים, לא בטוחים ואחוזי בטיחות.

### 4️⃣ ניהול משתמשים
- Admin יכול ליצור Managers וEmployees.
- Manager יכול ליצור Employees בלבד.
- מערכת היררכית שמבטיחה שכל משתמש מקושר למנהל שלו.

---

## 🗂️ טכנולוגיות

- **Backend:** Node.js + TypeScript + PostgreSQL
- **Frontend:** React + React Query + TailwindCSS
- **Authentication:** JWT + Cookies
- **Email (לשכחתי סיסמא – בעתיד):** Nodemailer
- **Password Security:** bcrypt

## 🗄️ בסיסי נתונים

### Users
| עמודה        | תיאור |
|--------------|-------|
| `id`         | מזהה ייחודי |
| `username`   | שם משתמש |
| `name`       | שם מלא |
| `role`       | תפקיד (`employee`, `manager`, `admin`) |
| `area`       | אזור |
| `manager_id` | מזהה המנהל של המשתמש |
| `password`   | סיסמא מוצפנת |
| `created_at` | תאריך יצירה |
| `updated_at` | תאריך עדכון |

### Reports
| עמודה        | תיאור |
|--------------|-------|
| `id`         | מזהה ייחודי |
| `user_id`    | מזהה המשתמש שדיווח |
| `is_safe`    | סטטוס בטיחות (true/false) |
| `timestamp`  | זמן הדיווח |
| `latitude` / `longitude` | מיקום גיאוגרפי |
| `reason`     | סיבת הדיווח |
| `image_url`  | קישור לתמונה אם יש |
| `area`       | האזור של הדיווח |
| `shift_id`   | מזהה משמרת (לרוב null) |
| `created_at` | תאריך יצירה |

### Alerts
| עמודה            | תיאור |
|------------------|-------|
| `id`             | מזהה ייחודי |
| `report_id`      | מזהה הדיווח שיצר את ההתראה |
| `status`         | `pending` או `acknowledged` |
| `acknowledged_at`| תאריך סימון טיפול |
| `acknowledged_by`| מי סימן את ההתראה (manager) |
| `updated_at`     | תאריך עדכון |
